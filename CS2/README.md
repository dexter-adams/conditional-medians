# Conditional Medians for Cities: Skylines II

Requires Cities: Skylines II. Built against 1.6.4f1. The tool closes the junction opening in a road's existing physical median using the median piece already present in the road prefab. It reads both stock and Road Builder network sections.

## Build and install

Run `powershell -ExecutionPolicy Bypass -File .\CS2\build.ps1` from the repository root. The game folder comes from `-Game`, else from `CSII_INSTALLATIONPATH` (set when the game installs its modding toolchain), else Steam's default library. The script compiles the DLL, then builds the game UI module (the tool's button and panel) in `CS2\UI` with Node.js and webpack. The UI build needs the Cities: Skylines II UI template packages: run `npm ci` in `CS2\UI` once (it needs the network), or pass `-UINodeModules` (or set `MEDIANS_NODE_MODULES`) with an existing template `node_modules` folder; without either, the script uses the `UI\node_modules` of a Driveway Entries checkout beside this one when it exists (the author's other mod, built from the same template).

With the game closed, copy `ConditionalMedians2.dll`, `ConditionalMedians2.mjs`, `ConditionalMedians2.css` and `ConditionalMedians2.mjs.LICENSE.txt` from `dist\CS2` to `%USERPROFILE%\AppData\LocalLow\Colossal Order\Cities Skylines II\Mods\ConditionalMedians2\`. The game loads the `.mjs` and `.css` beside the DLL at start.

## Publish to Paradox Mods

The page is `CS2\Properties\PublishConfiguration.xml`, with its images in `CS2\Properties\Screenshots\`: the featured image `conditional-medians-featured.jpg` (the thumbnail) and the numbered screenshots. The mod is Paradox Mods mod 168662 (`ModId`), so uploads need the mod owner's Paradox account, which the game's ModPublisher uses from the game's sign-in. Keep the version the same in `ModVersion`, `CS2\Source\AssemblyInfo.cs` and `CS2\UI\mod.json`, run `build.ps1`, write the `ChangeLog`, then run `powershell -ExecutionPolicy Bypass -File .\CS2\publish.ps1 -Command NewVersion` for a new build or `-Command Update` for page-only changes. The script uploads only the four runtime files and asks for the mod's name first; in a terminal that cannot answer the prompt, pass `-ConfirmName 'Conditional Medians'`. `-Command Publish` is the first upload, already done on 2026-11-21; it needs `Disclosure` filled in and prints the new mod's id for `ModId`. Paradox Mods offered no AI-disclosure tags for the game on 2026-11-21, so leave `AiTag` commented out: any value stops the upload.

## Use

- Click the round blue median button in the top-left row of mod buttons, or press F8, to start the median tool. A panel opens on the left. Point at a junction anywhere on its pavement, or on a road within about 30 m of it: the tool outlines the median opening in blue when it can be closed, in orange when it is closed (a click reopens it), and in red when it cannot be closed yet, and the panel and the cursor tooltip say why. Red curves mark the permitted turns that cross the median. A grey dot marks a node with no median opening. Left-click to close or reopen; right-click, F8, the button or the panel's X leave the tool. While the tool is on, every closed median keeps a faint orange outline.
- The two aligned approaches must use the same road prefab and matching physical divider. Painted center lines, roundabouts, platforms, tunnels, elevated approaches, and crossroads where both roads are divided are outside the supported set.
- At a T-junction the side street may be a divided road too, of the same type as the through road or another. The through road's median closes under the same rules, and the side street keeps its own median end exactly as at the open junction: its median is not drawn into the junction, and its crosswalks stay as they were. Forbid the side street's left turn out and the through road's left turn in first, as at any other junction; the tool draws them in red. A divided side street gets no through-lane strip (see below).
- Use the game's turn restrictions or Traffic's lane connector to remove connections that cross the median before closing the opening. The game and Traffic save those rules. The mod saves the toggle on the junction with references to the two approaches. Traffic's rules last only while Traffic is loaded: without it the crossing turns come back, and the closure stays closed to traffic but its median is not drawn.
- Removing the mod is safe: the game skips the mod's saved records and the closed junctions load as ordinary open junctions. The game keeps the closed bit in its own junction flags, though, so a city saved without the mod comes back with closed bits and no closures; the mod clears those after each load ("Cleared N closed-median mark(s)" in the log). A closure whose roads come from a mod that is missing (Road Builder) is released when the city loads.
- The renderer checks whether the native-width divider fits between the through lanes. If the fit fails, the junction keeps its regular road surface and the saved traffic closure stays active. The tool's panel shows the reason when you point at the junction, and the mod log records it.
- The game's turn signs only make a turn more expensive, so vehicles still take a forbidden turn now and then. While a median is closed, the mod therefore removes every car turn that crosses it from the game's route network (a runtime change the game rebuilds on every load; nothing is saved). Vehicles whose planned route still uses such a turn plan again before they reach it; a vehicle already in the turn finishes it. A newly closed median is drawn once those vehicles have left the junction (at most about 30 seconds of game time, which stands still while the game is paused); the panel shows how many it waits for and the time left. Reopening the median gives the turns back at once.
- Once the closed median is drawn, the lines beside it on both approaches (Curbside's, or the game's where it draws them) are continued through the junction in the same colour and style. Where a line meets a stop bar it stops short of the bar on both sides, with the gap Curbside leaves behind it. They are drawn by this mod at runtime and never saved, so a city keeps nothing of them without the mod. Reopening the median removes them.
- A closed junction keeps its crosswalks across the divided road, one on each carriageway, ending at the median; pedestrians cross over the closed median, and with traffic lights they keep their crossing phase. A mouth whose crosswalk was removed with the game's Crosswalk tool has no crossing at all, as at the open junction. The continued line stops 5 cm short of each zebra and resumes beyond it, and nothing is drawn between a stop bar and the zebra behind it. Curbside's lined crosswalks cut the line across both of their lines; its invisible crosswalks do not cut it.

## Geometry and testing

- Both curbs share one centerline fitted to the native road's positions and tangents. A joint fit gives both node halves the same curb positions and derivatives at their meeting point. The junction's vertex mapping retains the width of the curb tread through that join. The renderer measures the curb width from the built-in mesh and reuses the game's materials and tessellation.
- Tiled median pieces use a single distance along the centerline for texture placement. When the native median can use its own pair of render curves, both curbs and the median surface use the same distance at each cross-section, independent of the junction pavement. This keeps the curb joints square and preserves the original material detail. Other layouts use the regular junction deformation. Texture mapping is cached and reapplied when the relevant batches update.
- Tested in the game on a straight and a curved stock Four-Lane Divided Road junction, a sharply offset Road Builder junction next to a Driveway Entries curb cut, the game's grass upgrade on both divided roads, and divided side streets at T-junctions, with Traffic, Traffic Tool Essentials, Road Builder, Driveway Entries and The Curbside Mod loaded, and with this mod alone. The closed dividers and Traffic's lane connections returned after restarting and reloading. A saved closure is fitted again after loading. Curb stones keep their length through the junction, and the pattern restarts at the second mouth when the next texture repeat is out of reach. The lane pavement sits a few centimetres under the divider's skirt.
- With the game's grass upgrade, upgrade both segments at a junction. While only one is upgraded, the closure keeps blocking traffic and the median is drawn again once both match. A road upgrade can change Traffic's lane connections at the junction. Check that no turn crosses the median afterwards.
- At a T-junction the side street's pavement fans across the through road and shows as a triangle on its lanes. On the dedicated-mesh path the mod draws the through road's lanes on that side as one strip across the junction, seated on the pavement, with both long edges ending in low steps. To seat it, the mod also evens out the height of the side street's middle line between its mouth and the median, which the game's terrain and node objects follow too. A junction keeps the triangle when the strip would float more than 8 cm (a crest of about 3% or more), when the side street is divided (its junction mesh already uses the shape rails for its median's end), when the side street is too narrow, when the junction bends sharply, or when another closed junction already draws a different strip through the same side-street composition; such a junction gets its strip once the other no longer draws it. Junctions with different lanes on the same side-street mesh otherwise get separate strip meshes. When another mod draws a side street's junction with its own copy of the mesh (Driveway Entries does at a nearby entry), the copy cannot carry the strip, so that side street gets the game's own mesh and no strip until the city is loaded again; a through road drawn that way gets the native divider. The mod log reports each strip and each of these reasons.
- Create `diagnostics.txt` in `%USERPROFILE%\AppData\LocalLow\Colossal Order\Cities Skylines II\Mods\ConditionalMedians2\` (however the mod was installed) to log each closure's rails, sync data, texture stations and mesh pieces. The file is read again every second while the game runs. The lines `strip=off`, `settle=off`, `clearance=0.02`, `lift=0.05` and `reverse=on` in it adjust the through-lane strip without a restart. `native=1234` draws the divider of the closed junction with that entity index (as the log prints it) with the game's native deformation, together with every junction that shares its road compositions, to test the fallback. `streets=native` gives every side street the game's own junction mesh back. Each change of the file also logs every road's compositions, drawn meshes, held junction geometry and render batches at closed junctions. While the file exists, each closed junction logs, whenever its median lines change, why each marking near its mouths was taken or passed over and which stop bars and crosswalks cut the lines (`DIAG lines`); a change of the file also lists the crosswalk lanes around each closed junction (`DIAG crossing`).
- At the sharply offset Road Builder junction, the native median is 4.20 m wide. The fit failed the travel-lane clearance check, so the mod keeps the saved traffic closure and displays the regular junction surface.

Run `dotnet run --project CS2/Tests/GeometryChecks.csproj` to check native join and tangent alignment, constant-width offsets, winding, lane clearance, repeating texture phase, and the through-lane strip at the two logged junctions: its vertex lattice, its seating on the pavement as the strip's mesh draws it, the same junctions mirrored and bent over a crest or into a sag, and its rails. The checks need .NET 8 and the game's managed DLLs: they use `CSII_MANAGEDPATH` (set by the game's modding toolchain), else Steam's default library; otherwise pass `-p:GameManaged=<game folder>\Cities2_Data\Managed`. These checks model the junction's mesh deformation on the CPU.
